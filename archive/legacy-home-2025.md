# Legacy portfolio home (historical record)

This file records the role of the former root `index.markdown` that was used by the portfolio before the 2026-09-17 curated-home migration.

The legacy home presented a broad feature-row catalogue including Some of my DATA, an interactive dashboard, myEcommerce, 2Digit, NetProof, ThatsAllCloud, HappyCustomer, SimplEcomm and Fitness Tracker, with image-based cards and links to copied project folders inside this repository.

It was removed from the repository root because Jekyll treated it as a second home page and it conflicted with the newer `index.html`. The exact historical source remains recoverable from Git history at commit `8ef589207d3d92024d20cd4f6e0f5c62bf4dd0c5` and earlier commits.

Do not restore this file to the repository root as `index.markdown` while `index.html` is the canonical home page, otherwise the root-page collision can return.
